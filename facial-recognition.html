Introduction

The project is an AI-based attendance system that integrates facial recognition to automate attendance marking. It leverages computer vision, machine learning, and data handling concepts.

Key Features

  • Facial Recognition: Detects faces using Haar Cascade Classifier.
  • Face Registration: Collects multiple images per user for dataset creation.
  • Model Training: Uses LBPH algorithm for robust recognition.
  • Real-Time Recognition: Identifies users with confidence scoring.
  • Attendance Logging: Saves records into Excel with Pandas.
  • GUI: User-friendly Tkinter interface for registration & recognition.
  • Ethics: Data stored locally with transparency.

Conclusion

This project demonstrates practical use of AI and computer vision for streamlining attendance processes while ensuring usability, accountability, and ethical considerations.
