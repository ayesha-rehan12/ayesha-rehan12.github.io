💬 RealTime Redis Chat Application

Course: Parallel & Distributed Computing

📌 Project Overview

  • Built a scalable real-time chat application using Node.js, Socket.IO, Redis, Docker, and Nginx load balancing.
  • Implemented distributed system concepts including concurrency handling and containerized deployment.
  • Achieved load balancing across multiple server instances for improved performance and reliability.

🛠️ Technologies Used

  • Backend: Node.js, Socket.IO
  • Message Broker: Redis (Pub/Sub)
  • Containerization: Docker
  • Load Balancing: Nginx

🔧 Key Features

  • Real-time messaging with Socket.IO
  • Redis Pub/Sub for message distribution across servers
  • Docker containerization for easy deployment
  • Nginx load balancing for horizontal scaling
  • Multiple room/channel support

📚 Learning Outcomes

  • Understood distributed system architecture
  • Implemented message queuing with Redis
  • Gained experience with Docker and container orchestration
  • Learned load balancing strategies with Nginx
