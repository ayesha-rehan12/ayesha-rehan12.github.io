Introduction

The Contact Management System is a C++ application using the Windows API. It allows users to add, view, search, delete, and sort contacts. Data is saved in a file for persistence even after closing the application.

Features

  • Add Contact: Save name & phone number.
  • View Contacts: Display stored contacts.
  • Search: Find contacts by name.
  • Delete: Remove contacts by name.
  • Sort: Alphabetically sorts contacts using Bubble Sort.
  • File Storage: Saves all data in contacts.txt.

Technical Details

  • Language: C++
  • Libraries: Windows.h, STL (vector, string, sstream)
  • Data Structure: Vector of contact objects
  • GUI: Input fields, buttons, labels using Windows API

Advantages

  • Simple and user-friendly.
  • Data persists across sessions.
  • Efficient data handling with STL.

Limitations

  • No duplicate check or phone format validation.
  • Bubble Sort is slow for large datasets.
  • Data stored as plain text (no encryption).

Future Improvements

  • Better validation for phone numbers and duplicates.
  • Case-insensitive & advanced search filters.
  • Additional fields (e.g., email, address).
  • Data encryption for security.
  • Modern GUI using frameworks like Qt.

Conclusion

This project demonstrates a functional, beginner-friendly contact manager in C++. It provides a foundation that can be expanded with modern features and improved security.
