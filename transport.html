🚌 Transport Management System

Course: Web Engineering | University: Fatima Jinnah Women University

📌 Project Overview

  • Developed a real-time university transport management system using React Native, Firebase, and Node.js.
  • Implemented live vehicle tracking, route management, and separate dashboards for Admins, Drivers, and Students.
  • Enabled efficient monitoring and management of university transportation services through role-based access.

🛠️ Technologies Used

  • Frontend: React Native (Mobile App)
  • Backend: Node.js, Express
  • Database: Firebase Firestore
  • Real-time: Firebase Realtime Database for live tracking
  • Authentication: Firebase Auth

🔧 Key Features

  • Live GPS tracking of university buses
  • Role-based dashboards (Admin, Driver, Student)
  • Route management and schedule viewing
  • Real-time notifications for bus arrivals
  • Student booking system for seats
  • Driver route assignment and navigation

📚 Learning Outcomes

  • Built full-stack mobile application with React Native
  • Integrated Firebase for real-time data synchronization
  • Implemented role-based authentication and authorization
  • Learned live GPS tracking implementation
