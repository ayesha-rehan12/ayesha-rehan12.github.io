🩸 Blood Bank Management System

Course: Object-Oriented Programming & Database Systems

📌 Project Overview

  • Developed a Blood Bank Management System showcasing encapsulation, inheritance, and polymorphism principles.
  • Designed normalized database schema and implemented SQL queries for efficient data retrieval and management.
  • Integrated backend logic with structured data storage for donor and blood inventory management.

🛠️ Technologies Used

  • Language: C++ / Java (OOP)
  • Database: MySQL / SQLite
  • Concepts: OOP Principles, Database Design, SQL

🔧 Key Features

  • Donor registration and management
  • Blood inventory tracking by blood type
  • Request management for blood units
  • Reports generation for stock levels
  • Encapsulation of donor and inventory data

📚 Learning Outcomes

  • Mastered OOP principles in real-world application
  • Designed efficient database schemas with normalization
  • Implemented complex SQL queries for data analysis
  • Understood data modeling relationships
