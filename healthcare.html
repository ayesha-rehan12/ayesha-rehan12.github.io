Introduction

The Healthcare Appointment Management System is a web-based application that simplifies managing appointments, patient records, payments, and feedback. It reduces manual paperwork, improves efficiency, and ensures secure handling of patient data.

Abstract / Project Overview

  • Patients can register and book doctor appointments.
  • Doctors are assigned to specific departments.
  • Admins manage all data securely.
  • Includes payments, prescriptions, and medical records management.

Technologies Used

  • Frontend: HTML, CSS
  • Backend: PHP
  • Database: MySQL
  • Server: XAMPP (Apache)

Database Design

Key tables include Patients, Doctors, Departments, Appointments, Payments, Medical_Records, and Feedback. Relationships are managed with foreign keys, ensuring data integrity.

Security Features

  • Prepared statements for SQL injection prevention.
  • Input sanitization and validation against XSS attacks.
  • Error handling for DB connection and query failures.

Challenges & Learnings

  • Integrating multiple modules with validations.
  • Designing relational schema with integrity constraints.
  • Learning secure PHP coding with prepared statements.
  • Improved UX/UI with CSS and frontend design.

Conclusion

The project successfully developed a full-stack healthcare system with database integration, secure forms, feedback handling, and admin control. It improved understanding of PHP-MySQL full-stack development and delivered a robust, functional solution for healthcare management.
